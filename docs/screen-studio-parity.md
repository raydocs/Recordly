# Screen Studio parity roadmap

This roadmap is based on Screen Studio's public product and guide pages. It is
an implementation checklist, not a claim of affiliation or pixel-for-pixel
copying.

## Current coverage

| Area | Recordly status | Next fidelity work |
| --- | --- | --- |
| Click auto zoom, manual zoom, zoom depth and animation | Available | Per-region instant animation and disable toggle |
| Smooth cursor, cursor themes, click effects | Available | Hide-on-idle and per-section cursor visibility |
| Background, padding, crop, aspect ratio, device frames | Available | More bundled glass/wallpaper presets |
| Trim, clips, speed regions, audio gain/normalization | Available | Typing-segment detection and suggested speed-up |
| Webcam crop, mirror, 9 positions, custom placement | Available | Dynamic camera layout timeline (in progress) |
| Captions and transcript editing | Available | Local model picker/prompt UX parity |
| RNNoise voice cleanup | Available | Editor-side per-track cleanup preview/toggle |
| H.264, HEVC and GIF export | Available | Batch export and quick-share widget |
| Presets and keyboard shortcuts | Available | Portable shared preset package |

## Major remaining feature groups

1. Dynamic camera layouts: fullscreen/default/hidden regions on a dedicated timeline.
2. Smart editing: typing detection, suggested speed-up, masks/highlights and command menu.
3. Audio workflow: bundled background music library and per-track AI cleanup controls.
4. Capture workflow: speaker notes/teleprompter, iPhone mirroring and recovery diagnostics.
5. Sharing workflow: quick export, batch export, shareable links and comments.
6. Project portability: shareable presets, raw-track extraction and stronger autosave recovery.
